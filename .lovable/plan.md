
# موقع تسجيل مخيم بركة 2

موقع متكامل ثنائي اللغة (عربي/إنجليزي مع RTL) لتسجيل العائلات النازحة في مخيم بركة 2، مع لوحة إدارة كاملة لمراجعة الطلبات وإدارتها.

## الواجهات (للمستخدم)

### 1. واجهة الترحيب (Landing)
- شعار المخيم (الصورة المرفقة) في المنتصف
- اسم المخيم: **مخيم بركة 2 / BARAKA 2 CAMP**
- تحت "إدارة": **زياد خالد محمد الزعانين**
- تفاصيل المخيم في بطاقة:
  - العنوان: أرض المشتل
  - رقم التواصل: 592244588
  - إحداثيات المنطقة: 34.5432440، 34.4550300
- زرّان كبيران: **تسجيل جديد** / **تحديث بياناتي (تسجيل دخول)**
- مبدّل اللغة عربي/English في الأعلى
- فوتر يحتوي جميع الحقوق محفوظة

### 2. واجهة الحساب
- **تسجيل جديد**: إنشاء حساب رب الأسرة
- **تسجيل دخول**: لتحديث البيانات لاحقاً
- **استرجاع كلمة المرور** عبر البريد

### 3. نموذج رب الأسرة (الخطوة 1)
- رقم الهوية (9 أرقام، فريد)
- الاسم الرباعي
- البريد الإلكتروني + كلمة المرور
- تاريخ الميلاد (مع حساب العمر تلقائياً)
- رقم الجوال + رقم جوال بديل (اختياري)
- الجنس
- الحالة الاجتماعية: متزوج / أعزب / أرملة / مطلقة / **مزيد** (حقل نص حر يظهر عند الاختيار)
- **الحالة الصحية لرب الأسرة** (نفس حقول الأفراد أدناه)

رسالة نجاح ثم الانتقال للخطوة 2.

### 4. بيانات السكن (الخطوة 2)
- مكان السكن الأصلي + أقرب معلم
- مكان السكن بعد النزوح: **مخيم بركة 2** فقط (مقفول، غير قابل للتغيير) + أقرب معلم
- عدد أفراد الأسرة (رقم) → يولّد نفس العدد من بطاقات الأفراد في الخطوة 3

### 5. بيانات أفراد الأسرة (الخطوة 3)
لكل فرد (ما عدا رب الأسرة) بطاقة قابلة للطيّ:
- الاسم الرباعي + رقم الهوية
- تاريخ الميلاد + **العمر يُحسب تلقائياً ويُعرض تحت تاريخ الميلاد**
- الجنس
- صلة القرابة (زوجة، ابن، ابنة، والد، والدة، أخ، أخت، أخرى)
- الحالة الصحية:
  - هل مصاب حرب؟ (نعم/لا) → عند نعم: **رفع صورة التقرير الطبي** (إجباري)
  - هل يعاني من أمراض مزمنة؟ → حقل نص يكتب فيه التفاصيل
  - للإناث البالغات: هل سيدة حامل؟ هل سيدة مرضعة؟
  - ملاحظات صحية إضافية
- زر **+ إضافة شخص جديد** لإضافة أفراد لم يُحتسبوا في العدد
- زر حذف فرد
- على مستوى الأسرة: هل يوجد شهيد للعائلة؟ → عند نعم: حقل صلة القرابة + الاسم

زر **إرسال الطلب** → الطلب يُسجَّل بحالة "قيد المراجعة".

### 6. صفحة "طلبي" (بعد تسجيل الدخول)
- عرض حالة الطلب: قيد المراجعة / مقبول / مرفوض (مع سبب)
- تعديل البيانات وإعادة الإرسال

## لوحة الإدارة (Admin)

دخول بحساب ثابت أُنشئه في قاعدة البيانات (سأطلب منك إيميل وكلمة مرور بعد الموافقة على الخطة).

### الميزات
- **داشبورد إحصائيات**: عدد الطلبات الكلي، قيد المراجعة، مقبولة، مرفوضة، عدد الأفراد الإجمالي، عدد المصابين، عدد الشهداء، عدد الحوامل، توزيع حسب الحالة الاجتماعية
- **جدول الطلبات** مع:
  - بحث (الاسم، رقم الهوية، الجوال)
  - فرز (تاريخ التسجيل، عدد الأفراد، الحالة)
  - تصفية (الحالة، الحالة الاجتماعية، يوجد مصاب، يوجد شهيد)
- **عرض تفاصيل الطلب** الكاملة + معاينة صور التقارير الطبية
- **قبول / رفض** الطلب (مع كتابة سبب الرفض)
- **تصدير CSV / Excel** لقائمة المسجلين وأفراد عائلاتهم

## التصميم

- ثيم احترافي مستوحى من الشعار: أزرق كحلي داكن (#1a2847)، ذهبي (#c9a961)، أبيض، خلفية ورقية فاتحة
- خط عربي واضح (Cairo / Tajawal) + Inter للإنجليزي
- تخطيط RTL كامل للعربية، LTR للإنجليزية
- بطاقات بحواف ناعمة، ظلال خفيفة
- استجابة كاملة للموبايل (مهم — معظم المستخدمين سيدخلون من الجوال)
- مبدّل لغة في الهيدر
- أيقونات lucide-react

## التفاصيل التقنية

- **Frontend**: React + Vite + TypeScript + Tailwind + shadcn/ui
- **Backend**: Lovable Cloud (Supabase)
- **i18n**: react-i18next مع ملفي ar.json و en.json + اتجاه dir ديناميكي
- **التحقق**: Zod في كل النماذج (طول الحقول، صيغة البريد، رقم هوية 9 أرقام، جوال 9 أرقام)
- **رفع الصور**: bucket خاص `medical-reports` (خاص، RLS — صاحب الطلب والأدمن فقط)
- **التصدير**: مكتبة xlsx في المتصفح من جانب الأدمن

### قاعدة البيانات
- `profiles` — بيانات رب الأسرة المرتبطة بـ auth.users
- `user_roles` (enum: admin, user) + دالة `has_role` SECURITY DEFINER (لمنع الـ recursion في RLS)
- `applications` — الطلب (مكان السكن الأصلي/الحالي، الحالة، سبب الرفض، يوجد شهيد + تفاصيله)
- `family_members` — أفراد الأسرة المرتبطون بالطلب
- `health_info` — معلومات صحية لكل فرد (مصاب حرب، تقرير، أمراض مزمنة، حامل، مرضعة، ملاحظات)
- RLS صارم: المستخدم يرى/يعدل طلبه فقط، الأدمن يرى الكل

## ما سأطلبه منك بعد الموافقة
1. الإيميل وكلمة المرور لحساب الأدمن الثابت
2. تأكيد رابط/نص الفوتر (مثلاً: "© 2026 مخيم بركة 2 — جميع الحقوق محفوظة")
