# بركة 2

إنشاء موقع كامل لتسجيل في مخيم بإسم بركة 2 هو الواجهة الاولى ترحيب واجهة الثانية واجهت تسجيل جديد أو  تسجيل بالفعل وهو تحديث بيانات واجهة التسجيل طلب بيانات رب الأسرة وهي رقم الهوية و الاسم رباعي و الايميل و كلمة مرور و تاريخ ميلاد و رقم جوال و رقم جوال بديل أن وجد و حالة متزوج أو اعزب أو أرملة أو مطلقة أو مزيد و هو كتابة ماذا و ايضا بعد تسجيل بنجاح هذه معلومات بنجاح طلب دخول الى واجهة وهي مكان سكن الاصلي اقرب معلم و سكن بعد النزوج و اقرب معلم لازم اختيار بركة 2 فقط و ايضا عدد أفراد الأسرة حسب عدد الأفراد الأسرة أيضا جميع بيانات الأفراد ما عدا رب الأسرة تمام وايضا إضافة  زر شخص جديد و الصورة المرفقة هي صورة شعار للمخيم و ايضا إضافة تفاصيل المخيم تحت إداة إدارة
